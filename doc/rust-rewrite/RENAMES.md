# C to Rust names

This table maps each C function, macro, type, enum constant and global that the Rust rewrite
renamed to its Rust name, so an upstream yabai fix can be found in the Rust code and ported. A C
name that is not listed kept its spelling, or took the phase 2 CamelCase form of a type or enum
constant. Rows are grouped by the C file that defines the name.

The older documents in this folder (`GLOSSARY.md`, `THREADS.md`, `patterns/`,
`TRANSLATION_PLAN.md`, `files/`, `sweeps/`, `state-access/`) use the phase 2 names, which are
the C names; this table translates them too.
